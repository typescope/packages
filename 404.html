404 – Package not found

The requested package does not exist in the Jo registry.

Each registered package exposes two files:

https://pkg.jo-lang.org/<package>.toml   ← registration metadata
https://pkg.jo-lang.org/<package>.jsonl  ← release index

Registration metadata (.toml)

name       = "greeter"
namespace  = "acme"
repo       = "github.com/alice/greeter"
registered = "2026-01-01"
publishers = ["alice"]

[owner]
name  = "Alice Smith"
email = "alice@example.com"

Release index (.jsonl)

One JSON line per published version, append-only:

{"version":"1.0.0","url":"https://...","sha512":"6f0d...","deps":{}}
{"version":"1.1.0","url":"https://...","sha512":"7a21...","deps":{"math":"^1.0"}}

To publish a package, see the registry repository.
